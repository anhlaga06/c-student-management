# Student Management System (C Language)

## 📌 Overview
A console-based Student Management System written in C.

This application allows users to manage student records using basic operations such as adding, displaying, searching, and deleting students.

---

## 🚀 Features

### 1. Add Student
- Add a new student with:
  - ID (integer)
  - Name (string)
  - GPA (float)

### 2. Display Students
- Display all students currently stored in memory

### 3. Search Student by ID
- Search for a student using their unique ID
- Show full information if found
- Display "Not Found" if the ID does not exist

### 4. Delete Student by ID
- Remove a student using their ID

### 5. Exit
- Terminating the program

### 6. Help
- Display usage instructions and available commands
